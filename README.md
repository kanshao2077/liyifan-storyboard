# 李一帆分镜skill

根据已经写好的教学口播，生成简洁的八列分镜表格初稿，供博主、制作和剪辑团队继续挑选与完善。

默认交付Markdown；明确要求Excel时交付xlsx。画面和备注采用博主认可样稿的简洁写法，具体节奏与效果由团队发挥。

## 使用

```text
使用 $liyifan-storyboard
根据以下口播原文生成分镜初稿。
完整口播：……
已有素材：……
```

输出保留八列：镜号、口播文案、画面描述、效果制作备注、剪辑备注2、提示词、一审结果、二审结果。两个备注列保留团队标蓝提示，审核列保留“及修改意见”。提示词和审核内容默认留空。

- 保留口播原文及顺序；制作指令放入备注。
- 每行都有对应口播，A/B播放和停顿等并入相邻口播镜头。
- 素材复用直接写“复用前面的案例”，不另编素材编号。
- 画面写展示形式，制作备注列素材，剪辑备注只留必要提示。
- 不额外附素材总清单或默认时间轴。
- 后续反馈只修改指定内容。

## 安装

本仓库根目录就是Skill目录。将仓库内容放入`~/.codex/skills/liyifan-storyboard/`，或让Skill安装器安装本仓库的根目录，名称使用`liyifan-storyboard`。

若同名Skill已存在，先比较已有定制再更新。明确指定的输出格式和本次用户要求优先。
